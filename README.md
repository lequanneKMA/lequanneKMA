- Hot paths in the scoring loop are written to hit **0 B/op** — no garbage collector pressure, even at 100K+ requests per second.
- Location-Service and Dispatch-Service talk exclusively through **Kafka**, so either side can be scaled, replayed, or redeployed independently.
